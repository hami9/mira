KG Kala — sample shop

This page exists to test the Mira live chat widget — open the bubble in the corner and send a message.

How is the widget added to this page?

With a single script tag:
<script src="/widget-dist/widget.js" data-widget-key="..."></script>
A custom colour can be set with data-color and the position with data-position; with no colour set, the Mira brand gradient is used.

What can you test here?

Sending and receiving messages in realtime, the typing indicator, the out-of-hours auto-reply, the AI bot's answer (if enabled), and the rating card once a conversation is resolved.
