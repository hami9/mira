English · فارسی

چه چیزی به شما می‌دهد

همه‌چیز روی سرور خودتان اجرا می‌شود — داده‌ی مشتری‌هایتان جایی نمی‌رود.

💬 چت زنده‌ی واقعی

پیام بلادرنگ با Socket.io، نشانگر تایپ، نشان پیام نخوانده، و تحویل idempotent که با قطعی شبکه پیام تکراری نمی‌سازد.

✦ هوش مصنوعی با دانش شما

ربات پاسخ‌گو با RAG روی پایگاه دانش خودتان، Copilot پیشنهاد پاسخ برای اپراتور، خلاصه‌سازی خودکار، و تحویل به انسان وقتی مطمئن نیست.

🛒 متصل به ووکامرس

اپراتور همان لحظه سبد خرید، تاریخچه‌ی سفارش و مجموع خرید مشتری را کنار گفتگو می‌بیند؛ پیام محرک سبد رهاشده هم دارد.

📊 گزارش و اتوماسیون

آمار گفتگو، زمان اولین پاسخ، CSAT، عملکرد هر اپراتور و خروجی CSV — به‌علاوه قوانین اتوماسیون و وب‌هوک با امضای HMAC.

🔒 امن از پیش‌فرض

ورود دومرحله‌ای، دسترسی نقش‌محور زنده از دیتابیس، CORS و CSP سخت‌گیرانه، محدودیت نرخ، و HTTPS خودکار با Caddy.

⚡ نصب در چند دقیقه

یک پکیج واقعی دبیان به‌همراه ابزار خط فرمان mira، یا ایمیج‌های آماده‌ی Docker — بدون نیاز به تنظیم دستی.

نمای محصول

داشبورد اپراتور، ویجت چت و دیزاین‌سیستم برند

نصب روی سرور

روی دبیان یا اوبونتو، سه دستور تا داشبورد آماده با SSL خودکار

# نصب پکیج (از بخش Releases)
sudo dpkg -i mira_*_all.deb || sudo apt -f install

# راه‌اندازی: تولید خودکار همه‌ی رمزها + پرسیدن دامنه‌ها
sudo mira setup

# بالا آوردن سرویس‌ها
sudo mira start

توزیع‌های دیگر (AlmaLinux، Rocky، Fedora) با package/install.sh — راهنمای کامل فارسی: INSTALL.fa.md
