What you get

Everything runs on your own server — your customers' data never leaves it.

💬 Real live chat

Realtime messaging over Socket.io, typing indicators, unread badges, and idempotent delivery that does not duplicate messages when the network drops.

✦ AI that knows your shop

An answering bot with RAG over your own knowledge base, a reply Copilot for operators, automatic summaries, and hand-off to a human whenever it is not confident.

🛒 WooCommerce aware

The operator sees the customer's cart, order history and total spend right next to the conversation — plus an abandoned-cart trigger message.

📊 Reporting and automation

Conversation volume, first-response time, CSAT, per-operator performance and CSV export — plus automation rules and HMAC-signed webhooks.

🔒 Secure by default

Two-factor login, role-based permissions read live from the database, strict CORS and CSP, rate limiting, and automatic HTTPS via Caddy.

⚡ Installs in minutes

A real Debian package with the mira command-line tool, or prebuilt Docker images — no manual configuration required.

Install on your server

On Debian or Ubuntu, three commands to a working dashboard with automatic SSL 

# install the package (from Releases)
sudo dpkg -i mira_*_all.deb || sudo apt -f install

# setup: generates every secret, asks for your domains
sudo mira setup

# bring up the services
sudo mira start

Other distributions (AlmaLinux, Rocky, Fedora) use package/install.sh — full guide: INSTALL.md
