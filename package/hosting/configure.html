آماده‌سازی میرا

این فایل را روی کامپیوتر خودتان باز کنید. اطلاعات به هیچ سروری ارسال نمی‌شود. فایل تنظیمات تولیدشده محرمانه است؛ آن را در پوشه خصوصی برنامه و بیرون public_html بارگذاری کنید.

پیش‌نیاز: Node.js ۲۲٫۱۲ یا جدیدتر، PostgreSQL با pgvector، Redis و اجازه اجرای دائمی پردازشگر پس‌زمینه. هاست فقط PHP برای موتور کامل کافی نیست.

دیتابیس خالی مخصوص میرا استفاده کنید؛ افزونه vector باید فعال یا قابل ساخت باشد. رمز داخل URL باید URL-encode شده باشد.

همه امکانات نسخه نصبی رایگان‌اند؛ هزینه میزبان و API جداست. سازنده: hami9.ir — مجوز AGPL-3.0
