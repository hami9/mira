اتصال ویجت لایو چت میرا (خودمیزبان) به وردپرس و ووکامرس.

== Description ==

این افزونه ویجت لایو چت میرا را در فرانت‌اند سایت شما نمایش می‌دهد (نه در پیشخوان) و از طریق یک
REST endpoint سفارشی، اطلاعات سبد خرید فعلی، تاریخچه سفارش و مجموع خرید مشتری ووکامرس را برای
اپراتور در داشبورد میرا کنار پنجره گفتگو فراهم می‌کند.

امکانات:

* تزریق ویجت فقط در فرانت‌اند (رنگ و موقعیت قابل تنظیم)
* پیش‌فرم خودکار نام/ایمیل برای کاربرانی که در وردپرس وارد شده‌اند
* پیام محرک سبد خرید رهاشده روی صفحات ووکامرس
* REST endpoint امن (`/wp-json/mira/v1/customer-context`) با احراز هویت کلید API

== Installation ==

1. پوشه‌ی `mira` را در `wp-content/plugins` قرار دهید (یا از پیشخوان آپلود کنید).
2. از صفحه‌ی افزونه‌ها، میرا را فعال کنید.
3. از «تنظیمات → میرا»، آدرس بک‌اند میرا، کلید ویجت و کلید API را وارد کنید.
4. همان کلید API را در تنظیمات داشبورد میرا («اتصال وردپرس/ووکامرس») هم وارد کنید.
